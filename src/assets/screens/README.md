# Product screenshots

Drop the real Astro-Menu screenshots in this folder. `product-gallery.astro` picks up
whatever is here automatically — no code change needed. Anything not listed below still
renders, using a title derived from the filename.

Use PNG or WebP. Portrait phone screenshots (roughly 375×812 or larger) look best.

| Filename            | What it should show                                                        |
| ------------------- | -------------------------------------------------------------------------- |
| `landing.png`       | Venue landing page — cover photo, logo, description, social links           |
| `menu-sections.png` | A menu section with items, prices and photos, section tabs pinned at top    |
| `item-detail.png`   | One item expanded — big photo, description, sizes/portions, add-ons         |
| `filter-meal-type.png` | The "meal type" filter sheet open                                        |
| `language-switch.png`  | The language picker showing Arabic / English                             |
| `macros.png`        | Items showing calories and macros (CAL / CARB / FAT / PRO)                  |

Order in the gallery follows the table above; anything else is appended after.

## Permission

These are real customer menus. Only publish screenshots you have the venue's permission
to use, and prefer ones where their branding is deliberate rather than incidental.
